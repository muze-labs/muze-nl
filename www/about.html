About

We've been creating, fixing and improving web applications and tools since 1998. We still think simple solutions are usually better: easier to understand, integrate, reuse, secure and maintain. Getting to simple is not always easy.

What we're doing now

Solid is the focus of our current strategy. We build and run Solid identity and storage infrastructure and develop applications on top of it. At the same time, AI is changing how software is built and what software can become, so we're experimenting with that transformation rather than treating it as a separate service.
