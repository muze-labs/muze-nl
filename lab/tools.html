Experiments

Experimental backend

SimplyStore

A deliberately simpler data backend and API. The dataset is kept directly available to queries, with JSONTag providing an on-ramp toward semantically meaningful data.

source SimplyStore →package npm →

Web plumbing

MetroJS

A Fetch-compatible HTTP client with middleware. It adds reusable clients, composition and optional OAuth/OIDC support without replacing the browser's Request and Response model.

docs MetroJS →source GitHub →

Experiment

SimplyFlow

We're experimenting with a different way to build reactive web interfaces without a large framework. SimplyFlow builds on things we've learned from SimplyView and SimplyEdit. We're using it to find out whether there's a simpler way forward.

experiment SimplyFlow →related SimplyView →

Hope / Cobalt
